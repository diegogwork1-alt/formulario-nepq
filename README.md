# formulario-nepq

Skill gratis para Claude Code, con el método que uso en **Flowboost Marketing**.

**Qué hace:** El formulario de varios pasos que cualifica: primero la situación y el problema, después a dónde quiere llegar y cómo se resuelve, y los datos al final. Te lo da en texto, para cualquier herramienta

**Qué te deja:** `formulario-nepq.md`

## Instalación

```bash
git clone https://github.com/diegogwork1-alt/formulario-nepq.git
mkdir -p ~/.claude/skills
cp -r formulario-nepq/formulario-nepq ~/.claude/skills/
```

Si solo la quieres en un proyecto, cópiala en la carpeta `.claude/skills/` de ese proyecto.

## Cómo se usa

Abre Claude Code en la carpeta de tu proyecto y pídelo con tus palabras, por ejemplo: «Rehazme el formulario, solo pido nombre y teléfono»
